# 💊 Medicine Tracker

A simple medicine tracking application built with Python and Streamlit. It helps users manage medicines, record dosage schedules, and track daily doses.

## 🚀 Live Demo

[**Open Medicine Tracker 💗**](https://medicine-tracker-n2l5dkjhjq64gwexv5gzu9.streamlit.app/)

## ✨ Features

* 💊 Add medicines and dosage details
* 🕒 Select medicine timing: Morning, Afternoon, Evening, or Night
* 📅 Set treatment start and end dates
* 📋 View active medicines
* 🔄 Manage medicine status: Active, Completed, or Stopped
* ✅ Record doses as Taken, Missed, or Skipped
* 📖 View dose history
* 📥 Download dose history as CSV
* 💾 Store medicine and dose records using SQLite
* 🌸 Simple and user-friendly interface

## 🛠️ Technologies Used

* Python
* Streamlit
* SQLite
* Pandas

## 💻 Run Locally

1. Download or clone this repository.

2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   streamlit run app.py
   ```

4. Open the local URL displayed in your terminal.
